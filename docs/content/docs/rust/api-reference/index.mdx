The SDK is the [`flexiq`](https://crates.io/crates/flexiq) crate.
`flexiq-core` is the engine underneath, re-exported in full — `flexiq::Storage`
and `flexiq_core::Storage` are the same trait — so anything the shell does not
wrap is one import away.

```rust
use flexiq::{FlexiQ, Outcome, TaskCall, EnqueueOptions, Debounce, Abort,
             WorkerBuilder, Task, StepHandle, current_step, PeriodicSpec};
```
