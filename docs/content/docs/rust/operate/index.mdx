A Rust worker is a binary you wrote and you deploy. There is no daemon to run
beside it and no broker to operate: the scheduler lives inside the process that
calls `spawn()`, and it reads and writes the backend directly.

## The two things to decide first

Which backend the producer and the worker share, and which process owns the
periodics. Periodic firing is per-scheduler and not leader-elected, so two
processes that both registered the same schedule can both fire it — register
periodics from one process.
