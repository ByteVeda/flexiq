Pick the topic you're working through. Each guide is self-contained, with code
samples, gotchas, and links to the relevant API reference. Subsystems with their
own surface — workflows, durable steps, the dashboard, dependency injection,
mesh, the attached executor, autoscaling — live under
[**Modules**](/node/modules); running flexiq in production lives under
[**Operate**](/node/operate).

New to flexiq? These are how-tos, not a course — the linear
[**Start here**](/node/getting-started) track is the one to read in order.
Evaluating rather than learning? [**Capabilities at a
glance**](/about/capabilities) is the one-page map.
