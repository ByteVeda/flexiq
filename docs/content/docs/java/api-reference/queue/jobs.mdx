## Results & cancellation

### `flexiq.getJob()`

{/* api:FlexiQ.getJob */}
```java
Optional<Job> getJob(String jobId)
```
{/* /api */}

A job snapshot — status, progress, timestamps. Empty when no job has that id.

### `flexiq.awaitJob()`

{/* api:FlexiQ.awaitJob */}
```java
Optional<Job> awaitJob(String jobId, Duration timeout)
```
{/* /api */}

Block until the job reaches a terminal state; throws once `timeout` elapses.

### `flexiq.getResult()`

{/* api:FlexiQ.getResult */}
```java
<R> Optional<R> getResult(String jobId, Class<R> type)
Optional<byte[]> getResult(String jobId)
```
{/* /api */}

The job's stored result, raw or [deserialized](/java/api-reference/result) into
`type`. Empty while the job is still running, and after its result TTL expires.

### `flexiq.cancel()`

{/* api:FlexiQ.cancel */}
```java
boolean cancel(String jobId)
```
{/* /api */}

Cancel a pending job. Returns `false` once it has started — use
`requestCancel` for a running one.

### `flexiq.requestCancel()`

{/* api:FlexiQ.requestCancel */}
```java
boolean requestCancel(String jobId)
```
{/* /api */}

Ask a running job to stop. Cooperative: the handler observes it through
`isCancelRequested` and returns.

### `flexiq.isCancelRequested()`

{/* api:FlexiQ.isCancelRequested */}
```java
boolean isCancelRequested(String jobId)
```
{/* /api */}

Whether a cancel has been requested for this job. Poll it from long-running
handlers; a job that never checks runs to completion.

### `flexiq.setProgress()`

{/* api:FlexiQ.setProgress */}
```java
void setProgress(String jobId, int progress)
```
{/* /api */}

Record 0–100 progress for inspection and the dashboard.

## Listing & errors

### `flexiq.listJobs()`

{/* api:FlexiQ.listJobs */}
```java
List<Job> listJobs(JobFilter filter)
```
{/* /api */}

List jobs by status, queue or task, newest first. `listJobsAfter` is the
keyset-paginated twin — pass a page's cursor back as `after`.

### `flexiq.jobErrors()`

{/* api:FlexiQ.jobErrors */}
```java
List<JobError> jobErrors(String jobId)
```
{/* /api */}

Per-attempt error history, oldest attempt first.

## Archive

Terminal jobs are moved out of the hot `jobs` table into the archive, so
listings and dispatch scans stay fast without losing the history. The sweep
belongs to the worker; the archive keeps its own
[retention window](/java/api-reference/queue/queues#retention).

### `flexiq.listArchivedAfter()`

{/* api:FlexiQ.listArchivedAfter */}
```java
Page<Job> listArchivedAfter(long limit, String after)
```
{/* /api */}

The archive, keyset-paginated and ordered by completed time. Pass the previous
page's cursor back as `after`, or `null` for the first page; the cursor on the
returned `Page` is `null` once there is nothing left.

Prefer this to an offset walk. An offset re-scans everything it skips, and a job
archived mid-walk shifts every later offset by one, so rows get seen twice or
not at all. Treat the cursor as opaque — do not build or parse one.
