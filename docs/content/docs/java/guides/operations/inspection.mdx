---
title: Job Management
description: "List and inspect jobs, manage the dead-letter queue, and pause queues."
---

Read and manage individual jobs directly from the `FlexiQ` handle. For
queue-wide health — stats, per-execution metrics, workers — see
[Monitoring](/java/guides/observability/monitoring).

## Jobs

```java
List<Job> failed = flexiq.listJobs(
        JobFilter.builder().status(JobStatus.FAILED).limit(50).build());
flexiq.getJob(id);       // Optional<Job>
flexiq.jobErrors(id);    // per-attempt error history
flexiq.cancel(id);       // cancel a pending job
```

`JobFilter.builder()` also filters by `queue(name)` and `task(name)` and pages
with `offset(n)`.

## Dead letters

```java
flexiq.listDead(50, 0);              // newest first: limit, offset
flexiq.listDeadByTask("send_email", 50, 0);
flexiq.retryDead(deadId);            // re-enqueue; returns the new job id
flexiq.deleteDead(deadId);
flexiq.purgeDead(olderThanMs);
flexiq.purgeDeadByTask("send_email");
flexiq.purgeCompleted(olderThanMs);
```

## Pause / resume

Per-queue operations live on the `Queue` handle from `flexiq.queue(name)`;
the global view stays on the client:

```java
flexiq.queue("default").pause();
flexiq.queue("default").resume();
flexiq.queue("default").isPaused();
flexiq.listPausedQueues();
```

## Periodic tasks

```java
flexiq.registerPeriodic(PeriodicTask.builder("nightly", "report", "0 0 0 * * *").build());
flexiq.listPeriodic();       // every registered task, enabled or paused
flexiq.pausePeriodic("nightly");
flexiq.resumePeriodic("nightly");
flexiq.deletePeriodic("nightly");
```
