{{ include "flexiq-server.fullname" . }} is installed.

{{- if .Values.attach.enabled }}

Executors attach to:

    FLEXIQ_ATTACH={{ include "flexiq-server.fullname" . }}-attach.{{ .Release.Namespace }}.svc:{{ .Values.attach.port }}

The scheduler starts on the first attach — with nothing attached it would claim
jobs no executor advertises, and each would fail once placement timed out.
{{- end }}

{{- if .Values.dashboard.enabled }}

    kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "flexiq-server.fullname" . }}-dashboard {{ .Values.dashboard.port }}:{{ .Values.dashboard.port }}
{{- if and (eq .Values.dashboard.auth "session") (not .Values.dashboard.adminPassword) (not .Values.dashboard.existingSecret) }}

No admin was bootstrapped, so the first visit runs the SPA's setup flow.

{{- if .Values.grpc.enabled }}

Producers dial the gRPC door at:

    {{ include "flexiq-server.fullname" . }}-grpc.{{ .Release.Namespace }}.svc:{{ .Values.grpc.port }}

It refuses every call until a token exists. Mint one per client:

    kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "flexiq-server.fullname" . }} -- \
      flexiq-server token create --name my-producer --scope produce

The token is printed once. Clients present it as `authorization: Bearer <token>`.
Revoke it with `flexiq-server token revoke <id>`, or from the dashboard under
Configuration → gRPC tokens; it stops working on the next call, with no restart.

Nothing here terminates TLS — the token proves who is calling, it does not
encrypt the connection. Terminate TLS in a proxy or a mesh in front of the
Service.

Jobs enqueued over this door land in namespace {{ .Values.namespace }}; jobs
written without a namespace are invisible to it.
{{- end }}

{{- if .Values.webhook.enabled }}

Sidecar injection is on. Annotate a pod template:

    metadata:
      annotations:
        flexiq.dev/inject: "true"
        flexiq.dev/command: "<the command that runs an executor in your image>"
        flexiq.dev/slots: "4"
{{- if .Values.attach.enabled }}
        flexiq.dev/attach: "{{ include "flexiq-server.fullname" . }}-attach.{{ .Release.Namespace }}.svc:{{ .Values.attach.port }}"
{{- if or .Values.attach.token .Values.attach.existingSecret }}
        flexiq.dev/token-secret: "{{ if .Values.attach.existingSecret }}{{ .Values.attach.existingSecret }}{{ else }}{{ include "flexiq-server.secretName" . }}{{ end }}"
        flexiq.dev/token-key: "{{ if .Values.attach.existingSecret }}{{ .Values.attach.existingSecretKey }}{{ else }}attach-token{{ end }}"
{{- end }}
{{- else }}
        # This release runs no attach listener, so point these at the scheduler
        # that does — another release, or one outside the cluster — along with
        # the Secret holding its token. An address with nothing behind it
        # injects sidecars that can never connect.
        flexiq.dev/attach: "<scheduler host:port>"
        flexiq.dev/token-secret: "<secret holding its attach token>"
        flexiq.dev/token-key: "<key within it>"
{{- end }}

The sidecar reuses the pod's own image, so nothing new is pulled.
{{- if eq .Values.webhook.failurePolicy "Ignore" }}

failurePolicy is Ignore: if the injector is down, pods are created without a
sidecar rather than not at all. Set webhook.failurePolicy=Fail once a workload
depends on being injected.
{{- end }}
{{- end }}
